[[HTTP]]

Можно разделить на типа:
1. Авторизация и аутентификация

`Authorization `
`Cookie`

2.  Типы данных

`Content-type` - указывает какой тип данных в теле запроса
`Accept` - указывает какие типы данных клиент принимает
`Accept-encoding` - указывает какой тип сжатия поддерживает (gzip, deflate ...)
`Accept-language` - язык, который предпочитает клиент
